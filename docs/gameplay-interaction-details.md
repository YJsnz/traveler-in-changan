# 游戏互动细节、地图细节与隐藏成就设计

## 目标

本作不是只让玩家读剧情，而是让玩家通过探索、观察、选择和回访理解长安。地图上的小物件、NPC 的移动、天气、灯火、招牌、账册、食物、器物都应服务于叙事。

互动设计原则：

- 可看见的细节尽量可互动。
- 同一地点在剧情推进后要有变化。
- 隐藏内容不阻断主线，但奖励观察力。
- 成就不只是打卡，而是记录玩家的行为倾向。
- 小玩法要贴合职业，不做脱离故事的小游戏。

## 全局互动系统

### 1. 观察

玩家靠近物件按交互键，可获得短句描述。描述分三类：

- 普通观察：增加时代质感。
- 线索观察：推进任务或解锁新问法。
- 角色观察：根据当前主角给出不同评价。

示例：

同一只香料袋：

- 沈砚：袋口不是被刀割开的，是被人匆忙撕开的。
- 安月支：苏合香受潮后会发苦，这袋货今晚卖不出去了。
- 柳照夜：香气太重，足以掩盖血腥味。

### 2. 询问

NPC 不只有一次对白。每个重要 NPC 至少有四种状态：

- 初见。
- 事件后。
- 相关线索获得后。
- 章节结尾后。

部分 NPC 会说谎。玩家可以用线索解锁“追问”。

### 3. 回访

每个箱庭地图至少有两次回访价值：

- 剧情状态改变。
- 隐藏物或隐藏 NPC 出现。
- 支线后续。
- 终章状态。

### 4. 职业互动

每名主角拥有独特地图互动：

- 沈砚：查脚印、辨伤口、威慑低阶敌人。
- 裴青禾：验印、调卷、识别伪文书。
- 安月支：估价、翻译、辨别货路。
- 段无归：破障、识别军中暗号、震慑旧卒。
- 柳照夜：诊脉、辨毒、临时配药。
- 纪闻笛：听音辨人、换装通行、演奏引开守卫。
- 卢怀璧：辨文风、辩论、破解字谜。
- 金错刀：护送、换位、识别伏击路线。

## 地图细节设计

### 西市主街

可互动细节：

- 市署木牌：显示今日闭市时辰。命案后被不良司封条盖住。
- 灯笼油盏：可发现灯油被湿灰堵住。
- 胡饼炉：初始能买胡饼，命案后炉火被浇灭。
- 货车轮辙：深浅不同，提示箱子重量异常。
- 铜铃柱：敲响后可让巡逻不良人聚集。
- 雨水石缝：血迹会随时间变淡，提醒玩家尽快调查。

隐藏互动：

- 连续调查三盏熄灭灯笼，可发现灯灭顺序不是随机，而是从仓库方向向外扩散。
- 夜巡开场若先帮助小孩找鞋，后续小孩会指出阿犁逃跑方向。

隐藏成就：

- `灯未尽灭`：在调查尸体前找出全部三处灯油异常。
- `不惊市声`：命案后不威吓任何平民，完成全部询问。
- `旧鞋新路`：完成破鞋案，并在终章让小满贴出第一张玄牒传单。

### 香料巷

可互动细节：

- 香料袋：不同主角可识别不同用途。
- 账板：正面是买卖，背面刻暗号。
- 晾货竹竿：可移动，露出后门。
- 胡商小神龛：供奉商路平安，安月支互动有特殊对白。

隐藏成就：

- `闻香识路`：不询问罗三娘，仅通过香料线索找到小仓。
- `三娘的账`：帮罗三娘保住账板，终章她会资助证据拓印。

### 茶肆后院

可互动细节：

- 客牌架：客人姓名可与乐坊名单交叉验证。
- 倒扣茶盏：藏有军牌拓痕。
- 茶水缸：可洗去物件表面泥土。
- 竹帘：风吹方向提示有人翻墙离开。

隐藏成就：

- `茶凉之前`：在命案后限定时间内找到倒扣茶盏。
- `不问也知`：不追问茶博士，通过客牌和脚印还原死者路线。

### 乐坊侧门

可互动细节：

- 门房名单：不同时间段名单不同。
- 乐谱碎纸：拼合后可得边曲暗示。
- 胭脂盒：纪闻笛章节可识别主人。
- 偷药妇人：沈砚放过她会影响柳照夜章节。

隐藏成就：

- `侧门听曲`：在不进入乐坊正门的情况下获得完整乐坊线索。
- `一念放行`：沈砚放过偷药妇人，并在柳照夜章看到她康复。

## 八名角色专属互动

### 沈砚

专属小玩法：

- 足迹比对：在地面选择两组脚印，判断是否同一人。
- 伤口判断：观察尸体伤口方向，推断凶手惯用手。
- 威慑：可快速获取信息，但可能关闭某些温和支线。

隐藏成就：

- `不用刀的不良人`：沈砚篇中所有平民询问不使用威慑。
- `卷宗之外`：发现父亲案卷中全部三处矛盾。

### 裴青禾

专属小玩法：

- 验印：对比印章缺口。
- 刮字：刮去文书浮墨，发现底层旧字。
- 调卷：按州县户役顺序整理档案。

隐藏成就：

- `一字千钧`：修正所有被写错的姓名。
- `无火副本`：不烧任何非必要档案，完成档案阁。
- `纸上有魂`：为城南旧坊全部无名墓补名。

### 安月支

专属小玩法：

- 估价：判断货物真实价值。
- 翻译：选择正确语义，不只是字面翻译。
- 货路推断：根据封蜡、香味、泥土判断路线。

隐藏成就：

- `五种话`：听完弥罗五种语言玩笑的全部变体。
- `不压价的一单`：对贫苦 NPC 不讨价还价完成交易。
- `新驼队`：完成三个商路支线，终章让驼队带出玄牒拓本。

### 段无归

专属小玩法：

- 识别军号：通过旧军暗号判断同袍身份。
- 破障：推开重物进入捷径。
- 压怒：控制怒意，避免在对话中动手。

隐藏成就：

- `刀未出鞘`：段无归篇中不杀任何旧军同袍。
- `一碗粟米`：完成所有旧卒祭奠。
- `活下来的人`：在梦魇战场中找到全部同袍名字。

### 柳照夜

专属小玩法：

- 诊脉：根据脉象、肤色、气味判断病因。
- 配药：在有限药材中选择药方。
- 辨毒：识别药材是否被替换。

隐藏成就：

- `药不误人`：所有诊病小事件一次配对正确。
- `救与不救`：治疗曾经害人的病人。
- `寺外一棚`：章节结尾后让三名病人继续来寺外看诊。

### 纪闻笛

专属小玩法：

- 听音辨人：通过脚步、笑声、咳嗽识别雅间客人。
- 换装通行：选择合适衣饰进入不同宴席区域。
- 演奏：用曲调影响 NPC 注意力。

隐藏成就：

- `一曲无人懂`：第一次演唱禁曲时不被任何普通客人识破。
- `记住他们的名字`：记录全部贵客真名。
- `不谢幕`：保护小学徒后离开梨园。

### 卢怀璧

专属小玩法：

- 辨文风：判断文章是否出自同一人。
- 对句：诗会中选择对句改变 NPC 态度。
- 策论反击：在 Boss 战中用证据破除舆论状态。

隐藏成就：

- `不作谀诗`：诗会中从不选择迎合权贵的句子。
- `字不是墙`：帮三名普通人完成书信或文契。
- `今年不考`：放弃本届科名后仍保留旧砚。

### 金错刀

专属小玩法：

- 护送站位：移动时保持目标在安全范围。
- 伏击识别：查看路边异常判断埋伏。
- 换位保护：战斗中替目标承受攻击。

隐藏成就：

- `镖在人在`：护送中阿珩从未倒地。
- `旧旗新路`：修补镖旗后仍选择放下它。
- `不走安全路`：最终选择带阿珩回长安作证。

## 全局隐藏收集

### 长安百物志

玩家调查时代物件后解锁图鉴：

- 鱼符
- 过所
- 市署木牌
- 胡饼炉
- 香料袋
- 牙人契
- 寺田田契
- 贡院封条
- 镖局保状
- 军中木牌

每个条目不写百科式说明，而写一段角色视角短评。

示例：

鱼符：

“能开宫门，也能关住一个人的嘴。铜做的东西，总比肉做的人硬。”——裴青禾

### 玄牒残墨

每章有 3 个可选残墨。集齐某章残墨，可在终章解锁额外证词。全部集齐可解锁隐藏结局旁白。

### 长安夜声

收集声音：

- 晨钟
- 暮鼓
- 驼铃
- 琵琶调弦
- 书页翻动
- 药炉沸声
- 雨打灯笼
- 城门落闩

这些声音可在主菜单的“回忆”中播放。

## 隐藏成就列表

### 探索类

- `长安眼明`：调查 100 个非主线可互动点。
- `夜雨无遗漏`：一个章节中找到全部隐藏物件。
- `回头是路`：在同一章节中完成 5 次有新内容的回访。

### 选择类

- `少用威风`：全游戏从不对平民使用威慑。
- `贵人也问`：对所有高位 NPC 使用追问。
- `不做清白梦`：接受每个主角至少一次道德灰色选择。

### 剧情类

- `八证同出`：完成八名主角篇章。
- `灯不灭`：终章公开全部证据。
- `长安仍醒`：完成隐藏结局旁白。

### 战斗类

- `破盾如断案`：累计破盾 100 次。
- `护住证人`：所有护送战证人未倒地。
- `刀火皆明`：用弱点系统击败所有章节 Boss。

## 互动如何反哺剧情

隐藏互动不只给奖励，还应改变后续叙事：

- 沈砚放过偷药妇人，柳照夜章能见到她康复。
- 安月支帮助外商，终章外商驼队愿意运送玄牒拓本。
- 裴青禾补全无名墓，终章有百姓愿作证。
- 段无归不杀旧军同袍，终章旧卒酒铺不会彻底空掉。
- 纪闻笛保护小学徒，终章禁曲由小学徒传唱。
- 卢怀璧帮助普通人写信，终章策论更快传播到坊间。
- 金错刀一路保护阿珩，终章阿珩作证时不会怯场。

这样玩家会感觉自己的游玩方式真的改变了长安，而不是只改变结算面板。
