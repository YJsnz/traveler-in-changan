# 可游玩人物篇章设计 v3：箱庭式多地图探索

## 设计目标

每名角色的篇章不再按“任务 1 到任务 10”线性推进，而是设计成一个 4 小时左右的小型箱庭章节。玩家进入一个主题区域，在多个小地图之间往返调查、战斗、解谜、完成支线。随着线索推进，NPC 位置、敌人配置、封锁道路、可互动物件都会变化。

每个角色篇章默认包含：

- 1 个章节枢纽地图。
- 3 到 5 个可探索子地图。
- 1 个中型封闭区域或迷宫。
- 3 条可选线索链，允许玩家用不同顺序推进。
- 3 条支线，分布在不同地图。
- 2 到 3 次地图状态变化。
- 1 场章节 Boss。
- 1 个结局代价。
- 1 份玄牒线索。

## 箱庭章节通用结构

### 阶段一：开放区域

玩家进入章节枢纽，认识主要 NPC，获得初始目标。此时大部分地图可进入，但关键区域被门禁、夜禁、身份、机关或敌人封锁。

### 阶段二：线索交叉

玩家可在多个地图中自由调查。每条线索都指向另一张地图，形成往返关系，而不是单向推进。

### 阶段三：区域变动

找到足够线索后，章节区域发生变化：夜色加深、巡逻增加、某个 NPC 失踪、某条路被封、某个地下入口开放。

### 阶段四：核心地图

玩家进入章节中型地图或迷宫。此处集中战斗、谜题、剧情反转。

### 阶段五：回到箱庭

迷宫后不立刻 Boss，而是回到原区域。NPC 对真相产生反应，支线收束，玩家作出道德选择。

### 阶段六：章节 Boss 与代价

Boss 战发生在一个之前去过、但状态已经改变的地图中。战后角色得到玄牒线索，也失去某种保护、身份、关系或信念。

## 1. 沈砚，长安不良人

主题区域：长安西市夜间箱庭  
章节枢纽：西市主街  
核心体验：夜巡、查案、询问、暗巷追踪  
结局代价：违抗不良司命令，被内部监视  
玄牒线索：军饷转运异常记录

可探索地图：

- 西市主街：商贩、脚夫、巡逻不良人、灯笼机关。白天是市井，夜里变成案发现场。
- 香料巷：罗三娘的摊位、胡商仓口、藏有气味线索的货袋。
- 茶肆后院：客人名单、茶博士证词、可偷听的雅间。
- 乐坊侧门：纪闻笛客串登场，能提供宴席时间线。
- 仓库地窖：章节中型地图，包含货架机关、地下水道、旧军藏身处。

线索链：

- 货物线：香料巷 -> 脚夫车辙 -> 仓库地窖。
- 人证线：茶肆后院 -> 乐坊侧门 -> 夜巡档案。
- 旧案线：案发尸体 -> 不良司档案暗格 -> 沈砚父亲旧卷宗。

地图状态变化：

- 初始：西市仍有摊贩，玩家以夜巡身份行动。
- 命案后：灯笼熄灭，巡逻封街，部分 NPC 换位置。
- 地窖开启后：旧军出现，街上开始有可疑跟踪者。

支线：

- 破鞋案：在主街和香料巷之间寻找孩子父亲的遗物。
- 旧刀鞘：在茶肆后院找到修刀匠，修复沈砚父亲遗物。
- 夜禁之外：在乐坊侧门决定是否放过偷药妇人。

章节 Boss：韩折冲，旧军首领。Boss 场地在仓库地窖深处，战斗中会点燃货架、改变可站区域。

## 2. 裴青禾，内廷书吏

主题区域：尚书省与宫外档案箱庭  
章节枢纽：尚书省外廊  
核心体验：调卷、印章解谜、宫门通行、身份风险  
结局代价：失去内廷书吏身份  
玄牒线索：灾民户籍转入寺田记录

可探索地图：

- 尚书省外廊：官吏流动、公告栏、门禁令牌。
- 抄录房：文书小游戏、错字修正、同僚闲谈。
- 档案阁：中型地图，书架机关、印章顺序、巡查路线。
- 宫门夹道：需要不同令牌通行，可偷听宦官与官员。
- 城南旧坊：核实户籍死者的真实家庭。

线索链：

- 户籍线：抄录房 -> 城南旧坊 -> 档案阁。
- 印章线：外廊公告 -> 宫门夹道 -> 卢承简私印。
- 家庭线：裴母药方 -> 旧坊医铺 -> 青禾旧罪。

地图状态变化：

- 初始：青禾可自由进入抄录房。
- 被诬后：内廷通行受限，需要绕路和伪装。
- 真相前夜：档案阁加强巡查，城南旧坊有人被灭口。

支线：

- 错字：修正军籍姓名，让一个人恢复身份。
- 母亲药钱：在宫门夹道与医铺之间做灰色选择。
- 空白墓碑：在城南旧坊为无户籍者立碑。

章节 Boss：卢承简。Boss 场地在档案阁，书架会移动，伪档会遮挡线索与 UI。

## 3. 安月支，粟特胡商之女

主题区域：西市胡肆与城外驿道箱庭  
章节枢纽：胡商小广场  
核心体验：交易、翻译、追踪货契、商路选择  
结局代价：被逐出旧行会  
玄牒线索：战时粮价被商会抬高的证据

可探索地图：

- 胡商小广场：多语言商贩、货币兑换、行会告示。
- 香料库：气味线索、货箱编号、隐藏账页。
- 酒肆二楼：牙人谈判、偷听、可贿赂 NPC。
- 城外驿道：驼队痕迹、伏击战、夜间探索。
- 行会账库：中型地图，账柜机关、护卫巡逻、商契谜题。

线索链：

- 货契线：胡商广场 -> 香料库 -> 行会账库。
- 驼队线：城外驿道 -> 酒肆二楼 -> 失踪驼铃。
- 父亲线：安父旧友 -> 囤粮真相 -> 私开粮仓记录。

地图状态变化：

- 初始：行会只是不信任安月支。
- 父亲被押后：广场商贩躲避她，价格上涨。
- 账库暴露后：行会护卫封锁城外驿道。

支线：

- 香料配方：在香料库和酒肆之间复原亡夫味道。
- 错译契约：帮助外商识破契约陷阱。
- 归乡歌：寻找母亲留下的粟特歌谣。

章节 Boss：康善宝。Boss 场地在行会账库，香粉幻影会制造多个假目标。

## 4. 段无归，河西旧卒

主题区域：旧卒酒铺与长安城墙下箱庭  
章节枢纽：旧卒酒铺  
核心体验：复仇追踪、旧军关系、战场回忆、暴力克制  
结局代价：放弃私刑，也失去支撑自己的复仇理由  
玄牒线索：边军断粮日期与朝廷账面不符

可探索地图：

- 旧卒酒铺：幸存者聚点，NPC 会随剧情争吵、离开或死亡。
- 城墙阴影：流民、旧军暗号、夜间伏击。
- 刘宅病院：目标官员病榻、守卫、证词。
- 废弃军械库：中型地图，旧兵器机关、爆药、旧军藏身。
- 梦魇战场：短暂进入回忆地图，重现断粮之夜。

线索链：

- 复仇线：酒铺 -> 刘宅病院 -> 灭口者。
- 旧军线：城墙阴影 -> 军械库 -> 葛长风计划。
- 记忆线：遗刀 -> 梦魇战场 -> 真实断粮日。

地图状态变化：

- 初始：旧卒酒铺还能维持平静。
- 刺杀失败后：刘宅加强守卫，旧军复仇派活跃。
- 爆药暴露后：城墙阴影变成追逐战区域。

支线：

- 断刀：找回同袍遗刀。
- 一碗粟米：为亡者做祭饭。
- 城中孩童：面对一个把段无归当英雄的孩子。

章节 Boss：葛长风。Boss 场地在废弃军械库，爆药倒计时迫使玩家快速决断。

## 5. 柳照夜，明镜寺医女

主题区域：明镜寺箱庭  
章节枢纽：寺前施药棚  
核心体验：诊病、药材推理、寺院暗面、救与不救  
结局代价：被逐出明镜寺  
玄牒线索：寺田兼并与药材税记录

可探索地图：

- 寺前施药棚：病人队列、药方选择、日常支线。
- 孤儿院：孩子证词、夜间失踪、情感线。
- 药库外间：药材品质、库存账、僧人巡查。
- 寺田账房：田契、借贷账、豪族往来。
- 地下药库：中型地图，毒雾、尸骨、隐藏田契。

线索链：

- 病症线：施药棚 -> 孤儿院 -> 地下药库。
- 药材线：药库外间 -> 寺田账房 -> 劣药来源。
- 师姐线：旧针包 -> 恶人管事 -> 柳照夜旧伤。

地图状态变化：

- 初始：寺院祥和，病人排队。
- 孩子病死后：孤儿院封锁，药库有人销毁证据。
- 老僧认罪后：寺中僧人分裂，部分 NPC 敌对。

支线：

- 三味药：为三名病人配药。
- 师姐遗物：寻找针包和旧病例。
- 救或不救：治疗一个罪有应得的人。

章节 Boss：慧严。Boss 场地在地下药库，毒雾会周期性改变可行动区域。

## 6. 纪闻笛，梨园乐伎

主题区域：梨园与权贵夜宴箱庭  
章节枢纽：梨园后台  
核心体验：演出、潜听、换装通行、曲谱解谜  
结局代价：唱出禁曲，失去梨园庇护  
玄牒线索：被拆成曲谱的证人口供

可探索地图：

- 梨园后台：排练、换装、学徒、乐器。
- 前厅戏台：演出小游戏、客人视线、公开对话。
- 贵客雅间：偷听、酒令、宾客名单。
- 乐器库：断弦、残谱、隐藏信件。
- 权贵夜宴：中型地图，需要身份、服装和曲目切换通行。

线索链：

- 阿簪线：后台 -> 乐器库 -> 夜宴逃走路线。
- 客名单线：前厅戏台 -> 贵客雅间 -> 真正宾客。
- 曲谱线：断弦 -> 残谱 -> 禁曲证词。

地图状态变化：

- 初始：梨园准备演出。
- 阿簪失踪后：后台紧张，雅间封锁。
- 禁曲拼合后：夜宴开启，梨园主人开始监视纪闻笛。

支线：

- 断弦：修复旧琵琶。
- 客人的名字：记住客人的真实称呼与习惯。
- 小学徒：保护即将被卖入乐坊的小女孩。

章节 Boss：秦娘与护院。Boss 场地在前厅戏台，曲调每三回合改变战场增益。

## 7. 卢怀璧，落魄士子

主题区域：贡院、书坊与士子街箱庭  
章节枢纽：士子街书坊  
核心体验：文字推理、诗会选择、贡院潜入、舆论压力  
结局代价：放弃本届科名  
玄牒线索：官员用边功换取科名的记录

可探索地图：

- 士子街书坊：书商、传抄本、流言。
- 贡院外场：落榜榜单、考生争执、巡夜学官。
- 诗会小楼：社交选择、权贵羞辱、可公开辩论。
- 墨坊：纸张、墨迹、刻版来源。
- 贡院封卷处：中型地图，封条机关、试卷调包、巡逻。

线索链：

- 文章线：书坊 -> 墨坊 -> 封卷处。
- 好友线：周知白家 -> 药铺 -> 偷文动机。
- 权贵线：诗会小楼 -> 贡院外场 -> 崔令仪门客。

地图状态变化：

- 初始：落榜流言四起。
- 舞弊指控后：士子街 NPC 对卢怀璧态度分裂。
- 贡院潜入后：巡夜加强，诗会变成公开审判。

支线：

- 代写家书：替不识字老人写信。
- 旧砚：找回父亲留下的砚台。
- 诗会选择：迎合权贵或坚持讽刺。

章节 Boss：崔令仪。Boss 场地在诗会小楼，舆论会削弱玩家，策论反击可破除。

## 8. 金错刀，女镖师

主题区域：镖局、城门与荒庙护送箱庭  
章节枢纽：金风镖局  
核心体验：护送、路线规划、伏击、防守、信任建立  
结局代价：失去镖局名声，成为被追捕的人  
玄牒线索：伪造军印与关键证人

可探索地图：

- 金风镖局：接单、镖师关系、训练场。
- 长安城门：检查、路线选择、追兵出现。
- 地下水渠：潜行、岔路、追逐。
- 城外荒庙：防守据点、少年逐渐开口。
- 废驿道：中型地图，伏击、护送、旧盗出现。

线索链：

- 护送线：镖局 -> 城门 -> 水渠或废驿道。
- 少年线：荒庙对话 -> 半枚军印 -> 真实身份。
- 旧案线：废驿道 -> 旧盗梁七 -> 金错刀失败往事。

地图状态变化：

- 初始：普通护镖任务。
- 城门暴露后：所有出口开始设卡。
- 少年身份揭露后：镖局也转为敌对。

支线：

- 破镖旗：修补镖旗，回忆第一次出镖。
- 一路同行：通过小事件让少年逐渐开口。
- 旧债：面对因她失败而失去家人的委托人。

章节 Boss：岳沉舟。Boss 场地在金风镖局训练场，敌人会攻击少年，玩家必须用保护和换位技能应对。

## 合流篇：八个箱庭变成一座长安

八名角色的个人篇章完成后，长安主城进入合流状态。此前各篇章的箱庭地图不消失，而是成为终章可回访区域：

- 西市主街出现不良司内斗。
- 尚书省外廊进入戒严。
- 胡商广场开始罢市。
- 旧卒酒铺人去楼空，只留下旧军暗号。
- 明镜寺施药棚被封。
- 梨园禁曲在街头流传。
- 士子街开始传抄卢怀璧策论。
- 金风镖局悬赏金错刀。

终章不是一条直线，而是让玩家回访这些曾经熟悉的箱庭区域，按自己掌握的证据顺序布置公开计划。八个角色的故事因此真正归于同一个主线，而不是只在剧情里口头合流。
